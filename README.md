# প্রশ্নব্যাংক — University Admission Prep App

ফোন থেকে সম্পূর্ণভাবে পরিচালনাযোগ্য একটা বিশ্ববিদ্যালয় ভর্তি পরীক্ষার প্রশ্নব্যাংক অ্যাপ।

## স্ট্যাক
- React + TypeScript + Vite
- Tailwind CSS
- `src/data/questions.json` — সব প্রশ্ন এখানে ফ্ল্যাট JSON আকারে থাকে (কোনো backend/database লাগে না)
- GitHub Pages — ফ্রি হোস্টিং
- GitHub Actions — push করলেই auto build + auto deploy

## ধাপ ১: GitHub-এ রিপো বানাও
1. GitHub-এ নতুন একটা **public** repository বানাও, নাম দাও যা খুশি (যেমন `admission-question-bank`)
2. এই পুরো ফোল্ডারের সব ফাইল সেই রিপোতে আপলোড করো (GitHub মোবাইল ওয়েবসাইট থেকে "Add file → Upload files" দিয়ে, অথবা Termux থেকে `git push`)

## ধাপ ২: base path ঠিক করো
`vite.config.ts` ফাইলে এই লাইনটা তোমার রিপোর নাম অনুযায়ী বদলাও:
```ts
base: '/তোমার-রিপোর-নাম/',
```
আর `manifest.start_url` ও `scope`-ও একই নামে বদলাও।

## ধাপ ৩: GitHub Pages চালু করো
রিপোর **Settings → Pages** এ গিয়ে "Source" এ **GitHub Actions** সিলেক্ট করো। এরপর থেকে `main` ব্রাঞ্চে যেকোনো push করলেই `.github/workflows/deploy.yml` অটোমেটিক build করে সাইট পাবলিশ করে দেবে।

তোমার সাইট পাওয়া যাবে: `https://তোমার-ইউজারনেম.github.io/তোমার-রিপোর-নাম/`

## ধাপ ৪: নতুন প্রশ্ন যোগ করা (তোমার ওয়ার্কফ্লো)
এই অ্যাপে user-facing কোনো ছবি-আপলোড/OCR ফিচার নেই — কারণ OCR তোমার (এডমিনের) ডাটা-এন্ট্রির জন্য, ইউজারের জন্য না। প্রক্রিয়াটা এরকম:

1. প্রশ্নব্যাংক বইয়ের পাতার ছবি তোলো
2. অ্যাপের **আরও → প্রশ্ন যোগ করো (Admin)** পেজে গিয়ে "AI প্রম্পট কপি করো" চাপো
3. সেই প্রম্পট + ছবি Claude-কে (বা অন্য কোনো AI-কে) দাও — সে OCR করে schema অনুযায়ী JSON বানিয়ে দেবে
4. সেই JSON Admin পেজে পেস্ট করে "যাচাই করো" চাপো
5. ঠিক থাকলে "questions.json ডাউনলোড করো" চাপো
6. ডাউনলোড হওয়া ফাইলটা GitHub রিপোতে গিয়ে `src/data/questions.json`-এর জায়গায় আপলোড করে (রিপ্লেস করে) commit করো
7. GitHub Actions অটোমেটিক নতুন প্রশ্ন সহ সাইট rebuild করে দেবে (১-২ মিনিট লাগে)

### JSON schema (প্রতিটা প্রশ্নের গঠন)
```json
{
  "id": "du-2023-bangla-001",
  "university": "DU",
  "unit": "Ka",
  "year": 2023,
  "subject": "বাংলা",
  "chapter": "সন্ধি",
  "question": "প্রশ্নের টেক্সট",
  "options": ["ক", "খ", "গ", "ঘ"],
  "answerIndex": 0,
  "explanation": {
    "correct": "সঠিক উত্তরের ব্যাখ্যা",
    "wrong": ["প্রথম ভুল অপশনের ব্যাখ্যা", "দ্বিতীয়টা", "তৃতীয়টা"]
  },
  "timesAsked": 5,
  "language": "bn"
}
```
`timesAsked` দিয়ে 🔥⭐🔵 ট্যাগ ঠিক হয় (৭+ = 🔥, ৪-৬ = ⭐, ২-৩ = 🔵)।

## লোকাল প্রিভিউ (Termux থেকে, ঐচ্ছিক)
```bash
npm install
npm run dev
```

## ফিচার তালিকা
- University → Unit → Year → Subject → Chapter ফিল্টার সহ ব্রাউজ
- 🔥⭐🔵 Frequency ট্যাগিং
- Practice mode (10/20/50/100, random/subject/chapter-wise)
- My Mistakes (ভুল প্রশ্ন auto-track)
- Bookmarks
- প্রতিটা প্রশ্নে ডিটেইলড ✅❌ ব্যাখ্যা
- Progress Dashboard + Streak
- Mock Test (timer + negative marking, রেজাল্ট এখন সেভ থাকে ব্যাজ ও লিডারবোর্ডের জন্য)
- Weak Topic Analysis
- Powerful Search
- Daily Challenge
- Spaced Revision (মুখস্থ + ১/৩/৭/১৪ দিন রিভিশন)
- Dark Mode
- PWA — হোমস্ক্রিনে ইনস্টল করা যাবে, অফলাইনেও চলবে
- 🔊 Text-to-Speech — প্রতিটা প্রশ্নের পাশে স্পিকার আইকনে চাপলে প্রশ্ন+অপশন পড়ে শোনাবে (ব্রাউজারের নিজস্ব Web Speech API, কোনো এক্সট্রা সেটআপ লাগে না)
- 📄 PDF Export — সেভ করা প্রশ্ন ও ভুলগুলো পেজ থেকে "PDF এক্সপোর্ট করো" চাপলে ব্রাউজারের Print → Save as PDF ডায়ালগ খুলবে
- ⏳ Admission Exam Countdown — আরও → সেটিংসে পরীক্ষার তারিখ বসালে হোম পেজে দিন গণনা দেখাবে
- 🏅 Badges / Gamification — streak, accuracy, মক টেস্ট, মুখস্থ ইত্যাদির ভিত্তিতে ১৫টা ব্যাজ, আনলক হলে টোস্ট নোটিফিকেশন দেখায়
- 🔮 Predicted Questions — জেনারেটিভ AI না, বরং timesAsked ও সাম্প্রতিকতার ভিত্তিতে ডেটা-চালিত র‍্যাংকিং — কোন প্রশ্ন আবার আসার সম্ভাবনা বেশি তা দেখায়
- 🤖 AI Doubt Solver — চ্যাটবট, তবে **ইউজারের নিজের Anthropic API key লাগবে** (নিচে বিস্তারিত)
- 🏆 Leaderboard / Friends Compare — **শেয়ার-কোড ভিত্তিক**, লাইভ সার্ভার-সিঙ্ক না (নিচে বিস্তারিত)
- 🔔 Push Notification — **লোকাল ব্রাউজার রিমাইন্ডার**, সার্ভার-পুশ না (নিচে বিস্তারিত)
- 📝 Community Question Submission — **ম্যানুয়াল ইমেইল/কপি-পেস্ট ভিত্তিক**, সরাসরি অটো-যোগ হয় না (নিচে বিস্তারিত)

## ⚠️ কেন কিছু ফিচার "সম্পূর্ণ অটোমেটিক" না — এই অ্যাপের আর্কিটেকচার
এই অ্যাপের **কোনো ব্যাকএন্ড সার্ভার বা ডাটাবেস নেই** — এটা সম্পূর্ণ static React app, GitHub Pages-এ হোস্ট করা, আর সব ডেটা প্রতিটা ইউজারের নিজের ফোনের `localStorage`-এ থাকে। এই ডিজাইনের সুবিধা হলো এটা ফ্রি, দ্রুত, আর মেইনটেইন করা সহজ। কিন্তু তার মানে যেসব ফিচার সবার মধ্যে ডেটা শেয়ার করা লাগে (কমিউনিটি সাবমিশন, লিডারবোর্ড, সার্ভার-পুশ নোটিফিকেশন), সেগুলো একটা রিয়েল ব্যাকএন্ড ছাড়া "পুরোপুরি লাইভ/অটোমেটিক" বানানো সম্ভব না। তাই এই চারটা ফিচার নিচের মতো "সবচেয়ে কাছের সম্ভব" সমাধান হিসেবে বানানো হয়েছে:

### 🤖 AI Doubt Solver
- আরও → AI ডাউট সলভার পেজে গিয়ে নিজের **Anthropic API key** বসাতে হবে ([console.anthropic.com](https://console.anthropic.com) থেকে বানানো যায়)।
- Key শুধু তোমার ফোনের localStorage-এ সেভ থাকে, শুধু সরাসরি `api.anthropic.com`-এ যায় — এই অ্যাপের কোনো সার্ভারে না, কারণ সার্ভারই নেই।
- Key ছাড়া এই ফিচার কাজ করবে না, আর প্রতিটা API কল তোমার নিজের key থেকে বিল হবে (Anthropic-এর pricing অনুযায়ী)।

### 🏆 Leaderboard / Friends Compare
- সবার জন্য এক লাইভ লিডারবোর্ড বানাতে একটা সার্ভার লাগে, যেটা এই ফ্রি static app-এর নেই।
- এর বদলে: তুমি "শেয়ার কোড" জেনারেট করো (তোমার সেরা স্কোর দিয়ে বানানো একটা টেক্সট), বন্ধুকে WhatsApp/Messenger-এ পাঠাও, বন্ধু তার কোড তোমাকে দিলে সেটা "বন্ধুর কোড বসাও" ঘরে বসিয়ে তুলনা করতে পারবে।
- এটা ম্যানুয়াল, রিয়েল-টাইম না — কিন্তু কোনো ব্যাকএন্ড/লগইন ছাড়াই কাজ করে।

### 🔔 Push Notification
- সত্যিকারের push notification-এর জন্য একটা push server লাগে (Firebase Cloud Messaging বা সমতুল্য) — সেটা যোগ করা এই প্রজেক্টের স্কোপের বাইরে (অতিরিক্ত সেটআপ, খরচ, backend কোড লাগবে)।
- এর বদলে আরও → সেটিংসে "দৈনিক পড়ার রিমাইন্ডার" চালু করলে ব্রাউজারের Notification API ব্যবহার করে — অ্যাপ/ফোন সেই সময়ের কাছাকাছি খোলা থাকলে নোটিফিকেশন দেখাবে। ফোন সম্পূর্ণ বন্ধ থাকলে বা ব্রাউজার বন্ধ থাকলে এটা কাজ করবে না।

### 📝 Community Question Submission
- সরাসরি সবার প্রশ্নব্যাংকে অটো-যোগ করার মানে হলো ভুয়া/ভুল প্রশ্ন ঢুকে যাওয়ার ঝুঁকি — আর এটা করতে হলে একটা মডারেশন সিস্টেম + সার্ভার লাগে।
- এর বদলে আরও → প্রশ্ন সাবমিট করো পেজে ইউজার প্রশ্ন লিখে "তালিকায় যোগ করো" চাপে, তারপর ✉️ ইমেইল বা 📋 কপি বাটন দিয়ে সেটা সরাসরি অ্যাডমিনকে পাঠাতে পারে। অ্যাডমিন যাচাই করে normal Admin ওয়ার্কফ্লো দিয়ে questions.json-এ যোগ করবে।
- `src/pages/Community.tsx` ফাইলে `ADMIN_EMAIL` কনস্ট্যান্টটা নিজের ইমেইল দিয়ে বদলে নিও।
